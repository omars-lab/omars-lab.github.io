# Claude Code Techniques

These are ways of working with Claude Code that changed how I get things done. Each page covers
one technique: the problem it fixed, the lines to add to your own setup, and what it looks like in
a real session.

They go with my "How I Used Claude Today" posts on LinkedIn. A post has room for one idea and a
picture; the page has the rest.

## Techniques

Most useful to the most people first.

- **[Telling Claude When to Stop and Ask](/craft/generative-ai/claude-code-techniques/telling-claude-when-to-stop-and-ask)**:
  name the moments Claude should stop and ask you, and how to ask, so your decisions come back as
  clear choices instead of getting lost in a long reply.
- **[Picking the Prompt Cache Time Limit](/craft/generative-ai/claude-code-techniques/picking-the-prompt-cache-time-limit)**:
  measure the pauses between your turns before choosing a 5-minute or 1-hour prompt cache. How
  the cache works, with calculators to try your own pattern, is on
  [its own explainer page](/craft/generative-ai/claude-code-explainers/how-the-prompt-cache-works).
- **[Saving the Yeses in Claude's Memory](/craft/generative-ai/claude-code-techniques/saving-the-yeses-in-claude-memory)**:
  have Claude write down what you confirmed, not only what you corrected, so the approaches that
  worked survive into the next session.
- **[Sending Side-Quests to a Fork](/craft/generative-ai/claude-code-techniques/sending-side-quests-to-a-fork)**:
  hand side work to a forked agent that already knows the conversation, so only a short report
  comes back instead of every file it read.
- **[A Skill That Can't Approve Its Own Work](/craft/generative-ai/claude-code-techniques/a-skill-that-cannot-approve-its-own-work)**:
  let a skill suggest, and make the code refuse when it tries to mark its own suggestion as
  approved, so a guess and a decision never look the same.
- **[Sweeping Every Repo for Unpushed Work](/craft/generative-ai/claude-code-techniques/sweeping-every-repo-for-unpushed-work)**:
  one skill finds every repo with work that isn't on GitHub, writes each commit message from the
  diff, and scans for secrets before it pushes.
- **[Asking a Stronger Model What to Do Next](/craft/generative-ai/claude-code-techniques/asking-a-stronger-model-what-to-do-next)**:
  set a stronger advisor model and add a small Stop hook, so a long stretch of work ends with one
  suggested next step instead of a full stop.
- **[Pull Out the Patterns Before You Republish](/craft/generative-ai/claude-code-techniques/pull-out-the-patterns-before-you-republish)**:
  before reusing a detailed write-up elsewhere, separate the patterns tangled inside it and give
  each one its own general post.
- **[Diffing Regenerated Data by Key](/craft/generative-ai/claude-code-techniques/diffing-regenerated-data-by-key)**:
  when a script rewrites a data file, compare the rows by id instead of reading a line diff, so
  only the real changes show.

*For: anyone using Claude Code day to day who wants it to work more like a careful colleague.*
