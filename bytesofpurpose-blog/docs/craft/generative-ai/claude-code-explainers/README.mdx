# Claude Code Explainers

Each page here explains one part of how Claude Code works, with interactive widgets so you can
try it instead of only reading about it.

The [technique pages](/craft/generative-ai/claude-code-techniques) tell a story: what annoyed me,
what I did about it, and what it got me. When a technique leans on how something works, it links
to the section here instead of explaining it again, so one explainer can back several techniques.

  calculators for a day of pauses and a whole session.
